# Alina Lavoro - archivio separato (V35)

Sorgente dell'app operativa Alina Lavoro - archivio separato,
sincronizzato alla V35 pubblicata il 13 novembre 2026.

## Due progetti Apps Script, un repository GitHub

- App corrente: codice in apps/archivio-separato/.
- App storica V2.2.0/build 0428: src/, .gas/ e gas-current/.

Le app hanno identificatori Apps Script e distribuzioni differenti.
Gli script npm di deploy della radice sono destinati al progetto storico.

## Funzioni

- B&B: registrazione inizio/fine lavoro.
- Calendario: turni B&B e storico Ekom, modifica facoltativa.
- Impostazioni: Colore B&B; colore storico Ekom conservato.
- Backup JSON completo comprendente anche i turni Ekom.
- Registro PDF mensile Ekom rimosso.
- Icona originale comune: ../../assets/icona.png.

## Protezione dei dati personali

Questo repository e pubblico. Per sicurezza il file IdentityLab.js
contiene soltanto indirizzi dimostrativi owner@example.invalid e
alina@example.invalid: NON DISTRIBUIRE questa copia senza ripristinare
i due account ammessi attraverso la configurazione privata.
La V35 pubblicata conserva le due identita reali ed e invariata.
Credenziali OAuth e file .clasp.json restano esclusi da GitHub.
Il foglio Google delle presenze NON e incluso in questo repository.
